# SnowWow

Интерактивный адаптивный прототип приложения для горнолыжников и сноубордистов.

## Реализовано

- Каталог пяти направлений, поиск по названию/региону, фильтры и избранное.
- Canvas 3D-концепт процедурного рельефа: поворот мышью/пальцем, масштаб, сброс, расширенный вид, слои трасс и условное предупреждение.
- Ускоренная симуляция катания: старт, пауза, продолжение, завершение, статистика и сохранение истории на устройстве.
- Сезон, удаление демо-заездов, выгрузка JSON.
- Демонстрационный лидерборд с сортировкой и копирование приглашения в прототип.
- Демонстрация сохранения метаданных офлайн-пакета.
- Страницы первоисточников курортов; явные обозначения вымышленных данных.

## Ограничения

Настоящий GPS, API, авторизация, серверная синхронизация, реальный офлайн-пакет, AR и географически достоверный рельеф не подключены. Canvas использует условную математическую поверхность, общую для всех курортов. Иллюстрации карточек созданы средствами CSS. Никакие показатели трасс, погода, актуальные опасности и рейтинги пользователей не заявляются реальными. Данные истории и избранное сохраняются только в localStorage браузера. Внешний шрифт Manrope имеет локальный системный fallback.

## Структура

`dist/index.html`, `dist/style.css`, `dist/app.js`. Без сборки и зависимостей. Статический каталог dist.

## Проверено

- `node --check dist/app.js`.
- В браузере: главный экран и отображение модели; фильтр Подмосковья; выбор Сорочан; добавление в избранное; старт и пауза симуляции; завершение и сохранение; переход в сезон; сохранение результата после перезагрузки.
- CSS включает мобильную компоновку и нижнюю навигацию. Проверка на физическом iPhone/Android и измерение реальной фоновой геолокации не выполнялись: GPS в этом прототипе отсутствует.

## Версия 0.3

Стеклянные панели и новая фотозаставка. Локальное демо сообщества: анкеты, фильтр региона, приглашения, чат без доставки, скрытие анкеты, возрастное подтверждение для знакомств 18+. План проката с датой и комплектом, скачиваемая структура партнёрского предложения. Договоры и бронирования не подключены.

Фотографии: rosakhutor.ru/maps, krasnayapolyanaresort.ru (Риксос), volen.ru (отель). Материалы используются в закрытом прототипе; коммерческие лицензии не подтверждены. Для остальных направлений иллюстрации обозначены как концепты. Точный референс Nada по одному названию не идентифицирован.

## Версия 0.4 / проверенный NADO-референс

Изучен kava-studia/nado/src/App.tsx на текущей default-ветке: slate-цвета, light/dark, индиго/синие градиенты, glass header/navigation, rounded bordered cards. Добавлена переключаемая тема. Каталог: пять направлений с реальными изображениями; карточки с вкладками обзор/трассы/отели/билеты, просмотр фото, прямые ссылки на схемы и поставщиков. Проживание: даты, гости, номера, опция проката, сохранение черновика, экспорт и переход к поставщику. Реальные бронирования и цены не подключены.

В браузере на ширине 390 px проверены: открытие Красной Поляны, вкладка отелей, выбор дат и сохранение черновика с правильной ссылкой поставщика. Документы: partners.html и SnowWow_partner_launch_pack.md. Все медиа для закрытого прототипа; права для публичной коммерческой публикации ещё не подтверждены. Рендер 3D остаётся условным, закрыт в сворачиваемой секции до выбора пользователем.

## Версия 0.5 / Фото → 3D

На главной странице открыт интерактивный блок с четырьмя отдельными поверхностями. Геометрия вручную интерпретирует видимые признаки фото, не восстанавливается фотограмметрически:

- Роза Хутор: асимметричный гребень, широкая снежная поверхность; скрытая сторона, глубина и маршрут достроены.
- Сорочаны: параллельные подготовленные полосы, группы хвойных деревьев; расстояния, уклоны и маршрут условные.
- Шерегеш: заснеженный коридор между скальными выступами из пейзажного изображения сайта; это не подтверждённая трасса.
- Красная Поляна: крутая скальная вершина с летнего фото. Есть переключение между летним обликом и зимней стилизацией.

Ракурсы: общий, сверху, со склона. Вращение, масштаб, pinch, клавиатура, восстановление вида, исходное фото, объяснение наблюдений/допущений, переход к курорту. Анимированный пролёт проходит по условной линии и останавливается при скрытии страницы или уходе блока из области просмотра. WebGL с геометрией и цветами; при отсутствии WebGL используется программный перспективный рендер тех же мешей в Canvas 2D. Разрешение и плотность сетки ограничены; рендер без анимации выполняется по событиям. Это не точный цифровой двойник и не навигационная карта.

Проверено в браузере и мобильном iframe 390 px: отображение геометрии через программный renderer, смена Розы на Сорочаны, отдельная форма рельефа, вид сверху, запуск пролёта. Аппаратный WebGL на физическом iPhone/Android не проверялся.
