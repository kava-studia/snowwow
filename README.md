# SnowWow

Горнолыжный каталог, планирование поездок и GPS-запись в браузере.

- Приложение: https://snowwow.vercel.app
- Репозиторий: https://github.com/kava-studia/snowwow
- Статика: `dist/`, Vercel Framework Other, Output Directory dist. Сборка не требуется.
- Интерфейс: `snowwow.js`, `snowwow.css`; каталог: `resorts.json`; 3D: `slope3d.js`; GPS-вычисления: `gps-core.js`.
- Тесты: `node --test tests/gps-core.test.cjs`.
- План следующих этапов и границы текущих возможностей: [DEVELOPMENT.md](DEVELOPMENT.md).

Все пользовательские записи сохраняются только локально. Серверная авторизация, чат, подтверждение бронирования, платежи и нативный фоновый GPS ещё не подключены. Показатели катания вычисляются из реальных разрешённых пользователем GPS-точек; фиктивная активность не используется.

3D-сцены вручную смоделированы по видимым признакам фото, не являются фотограмметрией или точными картами склонов. Ссылки на первоисточники — в каталоге. До коммерческого распространения необходимо подтвердить права на медиа и договоры с операторами. Manrope поставляется по OFL; шрифты загружаются локально.
